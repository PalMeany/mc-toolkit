# Minecraft members the bridge touches by reflection, in Mojang (official) names.
#
# tools/gen_names.py maps every line to the obfuscated runtime names of the Fabric
# intermediary and Forge SRG namespaces for every supported release and writes the tables
# into src/main/resources (section [main]) and src/selftest/resources ([selftest]).
# Runtimes that use Mojang names (NeoForge >= 1.20.5, Forge >= 1.20.6, Fabric/NeoForge/Forge
# on the unobfuscated 26.x line) need no table: the names below are the runtime names.
#
#   C <class>                          class (owners and parameter types are added automatically)
#   M <owner> <name>(<param>,<param>)  method, matched by name + parameter types (return ignored)
#   F <owner> <name>                   field
#
# Alternatives for one feature (e.g. isOp(GameProfile) before 1.21.9, isOp(NameAndId) after)
# are all listed; the bridge picks whichever exists at runtime. Members that only exist on
# the Mojang-named 26.x line (no intermediary/SRG) are listed for documentation and simply
# produce no table rows.
